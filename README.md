# 🧰 Meridi Tools

**A little toolbox with no ads, no sign-up and no uploads.**
広告なし・登録なし・通信なしの、小さな道具箱。アプリが有料になったり、広告だらけになったりして困った人のための道具を、少しずつ詰めていきます。

👉 **[Open Meridi Tools](https://meridibrand.com/tools/)**

## Tools / 道具
| Tool | What it does | Open |
|---|---|---|
| 💸 **Split Bill & Tip** / 割り勘・精算＆チップ | Quick split (amount ÷ people), round up to 10 / 100 / 500 / 1,000, tick off who has paid, who owes whom in the fewest payments, tipping guide for 13 countries/regions, share link, print — great for year-end parties (忘年会・飲み会の幹事に) | [tools/split](https://meridibrand.com/tools/split/) |
| ⏱ **Timer & Scoreboard** | Six looks (F1, ice hockey, basketball, track, flip clock, hourglass), countdown, lap stopwatch, Tabata / HIIT / boxing intervals, two-team scoreboard | [tools/timer](https://meridibrand.com/tools/timer/) |
| ✂️ **Text Cleaner** | Full-width ⇔ half-width, address clean-up, find & remove invisible characters (ZWSP, BOM, smart quotes), PDF line breaks, accents & Unicode normalization, regex replace, character counter | [tools/text](https://meridibrand.com/tools/text/) |
| 🎲 **TRPG Dice Roller** | Dice notation (2d6+3, 4d6kh3, 3d6!, 5d10>=8, 4dF), 3D rolling d6, live probability chart, Call of Cthulhu 7e skill rolls, D&D advantage / DC, ability scores, macros, history | [tools/dice](https://meridibrand.com/tools/dice/) |
| 🔳 **QR Code Maker** | Direct QR codes that never expire — URL, text, Wi-Fi, contact, email, phone, SMS; colours, rounded dots, a 🐾 in the middle; PNG & SVG | [tools/qr](https://meridibrand.com/tools/qr/) |
| 📍 **Photo Location Remover** | See GPS location, date, camera, owner name & serials hidden in photos, then remove them without losing quality — nothing is uploaded | [tools/photo](https://meridibrand.com/tools/photo/) |

## Privacy
No ads, no sign-up, no tracking cookies. Nothing you type, paste or roll leaves your browser (a Split share link only goes to whoever you send it to — nothing is stored on a server). We only count page views with [GoatCounter](https://www.goatcounter.com/).
